Ejercicios guiados
==================
En esta colección de ejercicios deberás descargar unos programas de
ejemplo clicando sobre ellos con el botón derecho y seleccionando 
"Guardar enlace como...".
Luego abre esos programas con Scratch y observa como funcionan intentando
comprender el código.

#. Descarga el archivo :download:`scratch-b1.sb`.
   
   Abre el programa con el `editor de Scratch
   <https://scratch.mit.edu/projects/editor/>`__.
   
   Estudia el programa. Deberás pulsar la tecla espacio varias veces para
   ver cómo funciona. Para estudiar el código, debes mirar la zona de los
   disfraces.
   
   Modifica el programa scratch-b1 añadiendo otro personaje. Tienes que
   conseguir que uno "baile" al pulsar la tecla x y otro baile al pulsar
   la tecla m.

   Guarda el programa en tu carpeta de Scratch con el nombre **ejercicio_b1**.

#. Descarga el archivo :download:`scratch-b2.sb`.

   Abre el programa con el `editor de Scratch
   <https://scratch.mit.edu/projects/editor/>`__.
   
   Estudia el programa scratch-b2. Es parecido al scratch-b1, pero
   funciona al clicar la bandera.

   Observa que la chica baila siempre porque las instrucciones están
   dentro de un bucle por siempre.
   
   Modifícalo para que baile más rápido.

   Modifícalo para que baile en un escenario, por ejemplo el desierto,
   pero puedes elegir otro. Tendrás que ir al escenario y buscar en la
   librería.
   
   Modifícalo para que, además de bailar, esté recorriendo un círculo
   continuamente (dentro del bucle por siempre, haz que avance un poco
   y que gire un poco.
   
   Modifícalo para que, además, si pulsas las teclas de dirección (las 4)
   la chica se mueva un poco en la dirección pulsada.

   Guarda el programa en tu carpeta de Scratch con el nombre **ejercicio_b2**.

#. Descarga el archivo :download:`scratch-b3.sb`.

   Abre el programa con el `editor de Scratch
   <https://scratch.mit.edu/projects/editor/>`__.
   
   El programa scratch-b3 es similar al anterior, pero la chica se mueve
   de manera un poco aleatoria. Los números aleatorios son muy importantes
   para poder hacer videojuegos. Ellos nos van a permitir que los programas
   no se comporten siempre de la misma forma.
   Si los personajes siempre se comportaran siempre igual, no sería
   divertido.

   Modifica el programa para que la aleatoriedad sea mayor (que la
   posición de la chica cambie más).

   Guarda el programa en tu carpeta de Scratch con el nombre **ejercicio_b3**.


#. Descarga el archivo :download:`scratch-b4.sb`.

   Abre el programa con el `editor de Scratch
   <https://scratch.mit.edu/projects/editor/>`__.
   
   Prueba y estudia el programa scratch-b4. Cuando la pelota toca al gato,
   este cambia de color. En el programa del gato tenemos un bloque si.
   Si el gato está tocando la pelota, tiene un disfraz y si no la toca
   tiene otro.
   
   Mira el `tutorial sobre el bloque si (bifurcaciones)
   <https://www.apuntesmareaverde.org.es/grupos/tec/lomce/1eso/scratch1/tut_scratch/bifurcaciones.html>`__.

   Modifica el programa para que cuando la pelota toque al gato, diga 
   "¡AY!" además de cambiar de color.

   Modifica el programa para que cuando la pelota toque al gato, rebote
   (si toca el gato, gira 180º).
   
   Modifica el programa para que cuando la pelota toque al gato, la pelota
   gire una cantidad aleatoria alrededor de 180º (gira 180º mas un numero
   aleatorio entre -10 y +10º).

   Guarda el programa en tu carpeta de Scratch con el nombre **ejercicio_b4**.


#. Ejercicio final scratch-b5.

   Haz un programa en el que:
   
   * Un murciélago de un tamaño la mitad del que sale en la carpeta
     (1 punto).
   * Aletea por un bosque (1 punto).
   * Subiendo y bajando un poco aleatoriamente (1 punto).
   * Debe bajar un poco más de lo que sube (1 punto).
   * El murciélago se desplaza horizontalmente, pero al chocar con el
     borde rebota (1 punto).
   * En el medio del escenario hay una palmera (está en costumes -> things).
     Si el murciélago toca la palmera, sube un poco (1 punto).
   
   Guarda el programa en tu carpeta de Scratch con el nombre
   **ejercicio_b5_tu_nombre** y envíalo para calificación.
