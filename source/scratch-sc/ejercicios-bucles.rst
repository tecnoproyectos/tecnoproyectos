Ejercicios de bucles
====================

#. Descarga el programa :download:`scratch-d1.sb`.

   Abre el programa con el `editor de Scratch
   <https://scratch.mit.edu/projects/editor/>`__.

   Prueba y estudia el programa.   
   En este programa el gato cuenta gracias a las variables.
   
   Estudia el tutorial sobre variables: `Las variables en Scratch
   <https://www.youtube.com/watch?v=ymydVaLykGU>`__.

   También usamos el bloque de repetición.

   Modifica el programa para que cuente hasta el número 8.

   Guarda el programa en tu carpeta de Scratch con el nombre **ejercicio_d1**.
      
#. Modifica el programa para que cuente hasta desde el 2 al 6.

   Guarda el programa en tu carpeta de Scratch con el nombre **ejercicio_d2**.

#. Modifica el programa para que cuente desde el 2 hasta el 12, pero
   sólo los números pares.

   Guarda el programa en tu carpeta de Scratch con el nombre **ejercicio_d3**.

#. Modifica el programa para que cuente hacia atrás desde el 7 al 3.

   Guarda el programa en tu carpeta de Scratch con el nombre **ejercicio_d4**.

#. Los personajes de Scratch pueden pedirnos un dato que introduciremos
   en el teclado. Mira los tutoriales sobre mensajes.
   Haz un programa en el que el gato te pregunta tu nombre y te 
   responda "Hola ..." seguido de el nombre que has introducido.
   Necesitarás usar el operador de concatenación para unir mensajes como
   muestra en el tutorial de unir mensajes.
   
   Guarda el programa en tu carpeta de Scratch con el nombre **ejercicio_d5**.

#. Haz un programa que pida dos números y nos diga cuánto suman.
   
   Para ayudarte, estudia el `tutorial que explica cómo hacer cálculos aritméticos
   <https://apuntesmareaverde.org.es/grupos/tec/lomce/1eso/scratch1/tut_scratch/calculos.html>`__.

   Guarda el programa en tu carpeta de Scratch con el nombre **ejercicio_d6**.

#. Haz un programa en el que el gato pregunta un número y dice la tabla
   de multiplicar de ese número.

   Guarda el programa en tu carpeta de Scratch con el nombre **ejercicio_d7**.

#. Ejercicio final. Haz un programa en el que:
   
   * Un personaje diferente del gato, en un habitación (1 punto)
   * Te pregunta ¿cuanto vale a más b? (1 punto).
   * Donde a y b son dos números aleatorios entre el 1 y el 20 (2 puntos).
   * Si escribes bien la respuesta, el personaje dice "Bien hecho" (1 punto).
   * Si está mal la respuesta, el personaje dice "Te has confundido. 
     El resultado es..." (1 punto).
   * Hay una variable llamada contador que empieza valiendo 0 (1 punto)
   * Y que aumenta 1 con cada acierto (1 punto).
   * Cuando has conseguido 3 aciertos el personaje dice "¡Bravo! Has
     conseguido 3 aciertos" (1 punto),
   * Hace un pequeño baile (1 punto)
   * Y termina el programa (1 punto).

   Guarda el programa en tu carpeta de Scratch con el nombre
   **ejercicio_d8_tu_nombre** y envíalo para calificación.
