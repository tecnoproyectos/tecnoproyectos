Ejercicios de dibujo
====================
Con Scratch se puede dibujar. Los personajes tienen un lápiz.
Hay una instrucción para bajar el lápiz y otra para subirlo.
Si el lápiz está bajado y el personaje se mueve, dibuja una línea.

#. Descarga el programa :download:`scratch-c1.sb` de ejemplo.

   Abre el programa con el `editor de Scratch
   <https://scratch.mit.edu/projects/editor/>`__.
   
   Estudia el código para comprobar qué hace.
   
   Modifica el programa anterior para conseguir este dibujo 
   (que cambie el color del lápiz):
   
   .. figure:: _images/scratch-sc-c01.png

   Guarda el programa en tu carpeta de Scratch con el nombre **ejercicio_c1**.

#. Si quisiéramos hacer un cuadrado más pequeño habría que cambiar el
   avance en 4 instrucciones. Este resultado se conseguir hacer más
   fácilmente usando las herramientas de variables (zona naranja).
   Las variables son datos que se pueden cambiar y repetir durante el
   programa.
   
   Descarga y estudia el código de este programa :download:`scratch-c2.sb`.
   En la primera instrucción dice fijar el lado a...
   Prueba asignando distintos valores.

   Modifica el programa para que dibuje un cuadrado con tamaño de lado 40.
   
   Guarda el programa en tu carpeta de Scratch con el nombre **ejercicio_c4**.

#. Ejercicio final. Haz un dibujo utilizando los recursos aprendidos:

   * El dibujo debe presentar alguna simetría.
   * Debe tener al menos dos bucles de repetición, mejor si están anidados
     uno dentro del otro.
   * Se debe usar al menos una variable que cambie de valor durante la
     ejecución del programa.
   * El programa debe pedir un dato que se lea y el dibujo debe depender
     de ese dato.
